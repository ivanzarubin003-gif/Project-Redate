# Your Compater (v1.0.0)

**Your Compater** — это легковесная консольная утилита для разработчиков, предназначенная для тестирования локальных сред (environments), отладки игровых механик и автоматизации рутинных процессов взаимодействия с памятью процессов.

## Основной функционал
* **Environment Testing:** Анализ динамических изменений параметров среды в реальном времени.
* **Process Optimization:** Коррекция задержек (ping/latency) при взаимодействии скриптов.
* **UI/UX Debugging:** Визуализация скрытых элементов коллизии и триггеров на сцене.

## Системные требования
* Операционная система: Windows 10 / 11 (x64)
* Права администратора (необходимы для инжекта/чтения памяти отлаживаемого процесса)

## Установка и запуск
1. Перейдите в раздел **[Releases](ссылка_на_ваш_релиз)** и скачайте актуальный архив программы.
2. Распакуйте архив в удобную папку.
3. Запустите целевой плейс / среду разработки.
4. Запустите файл `YourCompater.exe` от имени администратора.

⚠️ **Важное примечание (False Positive):** 
Поскольку утилита использует методы динамического анализа и взаимодействует с памятью активных процессов для отладки, некоторые антивирусы (включая Windows Defender) могут ошибочно идентифицировать программу как нежелательное ПО. Это стандартное ложное срабатывание для софта такого типа. Рекомендуется добавить папку с программой в исключения антивируса перед запуском.
